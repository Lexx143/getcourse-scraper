# GetCourse Scraper

Чистый и масштабируемый парсер для GetCourse (niifittech.ru). Позволяет обходить тренинги, выгружать текстовые материалы и вставленные в них картинки прямо в формат Word (`.docx`), а также автоматически скачивать все встроенные видео в формате `.mp4` с помощью утилиты `yt-dlp`.

## 🛠 Подготовка окружения

1. Создайте виртуальное окружение и активируйте его:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Убедитесь, что в вашей системе установлена утилита [yt-dlp](https://github.com/yt-dlp/yt-dlp). В большинстве систем она может быть установлена через pip или пакетный менеджер (Homebrew, apt).

## 🍪 Авторизация (Экспорт Cookies)

Так как контент тренингов («Тело человека», «Ягодицы» и др.) закрыт, скрипту нужны ваши `cookies`, чтобы получать доступ к материалам от вашего имени. Это нужно как для выгрузки текста и картинок, так и для скачивания видео через `yt-dlp`.

1. Установите в браузер расширение для экспорта cookies (например, **Get cookies.txt LOCALLY** для Google Chrome / Edge).
2. Зайдите на сайт `niifittech.ru` и убедитесь, что вы авторизованы в своем аккаунте.
3. Откройте расширение и выгрузите cookies.
4. Сохраните скачанный файл строго под именем `cookies.txt` в корень этого проекта (в ту же папку, где находится `main.py`).

*(Файл `cookies.txt` уже добавлен в `.gitignore`, так что ваши сессионные данные в безопасности и не попадут в репозиторий).*

## 🚀 Запуск скрипта

Когда `cookies.txt` лежит рядом со скриптом, вы можете запускать выгрузку целых тренингов, просто передав ссылку на них.

Для выгрузки тренинга **«Тело человека»** (193 урока):
```bash
python3 main.py --url https://niifittech.ru/teach/control/stream/view/id/935159754
```

Для выгрузки тренинга **«Ягодицы»** (65 уроков):
```bash
python3 main.py --url https://niifittech.ru/teach/control/stream/view/id/935166293
```

### ⚙️ Как работает логика сбора:
1. Заходит на страницу тренинга (список уроков).
2. Собирает ссылки на все доступные уроки (парсит структуру).
3. Поочередно заходит в каждый урок (с безопасной паузой в 1 секунду между запросами, чтобы избежать блокировки со стороны GetCourse).
4. Создает в папке `data/` директорию с названием курса, а внутри — структурированные папки под каждый урок.
5. **Текст и Картинки**: Текстовые блоки (`.lite-block-live-wrapper`, `.v-spacing`) сохраняются в файл `content.docx`. Если в тексте встречаются картинки, скрипт автоматически скачивает их, вставляет в Word-документ на нужные места, а затем удаляет оригиналы картинок, чтобы не мусорить.
6. **Видео**: Скрипт находит все видео-ссылки (хэши или `iframe`) и **сразу же скачивает их** в папку с уроком с помощью команды `yt-dlp --cookies cookies.txt`. Если видео по каким-то причинам не скачивается (например, из-за специфичной защиты или ошибки), скрипт логирует эту ошибку и идет дальше.

⚠️ **Внимание**: Скачивание видео с полных курсов займет значительное время и потребует большого объема свободного места на жестком диске.
